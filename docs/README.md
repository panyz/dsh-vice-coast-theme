# 实测笔记（provenance）

这三个文件是设计阶段的实测记录，不是可执行代码的一部分：

| 文件 | 内容 |
| --- | --- |
| `shell-notes.md` | DSH Web 客户端的主题机制（`overrideTokens` 覆盖层、明暗属性、内联变量），字体与布局的原始尺寸，按引用次数排序的 token 覆盖表，"主题改不到什么"的清单 |
| `dom-notes.md` | 主界面各区域的结构与具体 CSS 值（侧栏、会话列、自己气泡、工具卡、代码块、diff、输入区、右栏），以及硬编码颜色清单 |
| `sample-palette.mjs` | 官方主视觉的取样脚本（`ffmpeg` 解码 + k-means），设计里那 6 个锚点就是它跑出来的 |

约定：

- 这里只保留**分析与结论**；安装包里提取出的 CSS 原文（`stock-tokens.json`、逐表 dump）不随仓库分发，需要时用本目录的方法自行从你自己安装的 DSH 里复现。
- 官方宣传图本身也不在仓库里：请自行下载，`sample-palette.mjs` 接受任意图片路径。

结论的时效性绑定在被测构建上（DSH Web，2026-11）；升级后请重新核对，尤其是硬编码颜色那一节。
